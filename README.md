# MarketReady

Marketing jobs and interview preparation for Chennai and Pondicherry.

## Phase 1 features

- Search and role filters
- Detailed role views
- Marketing Readiness Score
- Saved/applied/interview/offer tracker
- Job-specific WhatsApp mock-interview CTA
- Responsive mobile interface

This first version stores candidate tracker data locally in the browser. A future backend phase can add secure accounts, permanent storage and an admin dashboard.
